# Security Policy

## Reporting a Vulnerability

At **Tactic Space Tech**, we take the security and privacy of **Lumo** users seriously.

Please **do not** report security vulnerabilities through public GitHub issues. Instead, report potential vulnerabilities privately through our support channel:

- **Support Portal**: [https://getlumo.io/support](https://getlumo.io/support)

Please include:
1. Platform and app version (e.g., Lumo for macOS `v1.5.0` or Lumo for iOS `v1.4.0`).
2. Steps to reproduce or proof-of-concept details.
3. Expected vs. observed impact.

We review all security reports promptly and will coordinate remediation and disclosure with you.
